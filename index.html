Octobre 2026

Jeu du nombre caché en C#

Cadre de réalisation

Exercice de programmation réalisé en formation (BTS SIO, CNED), pour mettre en pratique les bases du langage C#. Projet individuel.

Description

Application en ligne de commande : un premier joueur saisit le nombre à trouver, puis le second propose des essais. À chaque essai, le programme indique si la proposition est trop grande ou trop petite, et affiche le nombre d'essais nécessaires une fois le nombre trouvé.

  • Variables, boucles while et structures conditionnelles
  • Contrôle de saisie avec try / catch : un message d'erreur s'affiche si l'utilisateur ne tape pas un nombre entier
  • Compteur d'essais
  • Code commenté et publié sur GitHub
